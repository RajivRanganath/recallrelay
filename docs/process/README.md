# Planning notes from development

RecallRelay is one project built by two contributors. To work in parallel on separate schedules, the build was divided into two areas with a fixed HTTP contract between them. These files are the planning notes from that period, kept as written: the original scope, the task board, decisions, start notes and the working arrangement. They describe how the work was organised, not how the product is divided.
