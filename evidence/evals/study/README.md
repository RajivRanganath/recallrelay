# Blank human-evaluation templates

These CSVs contain headers only: no participants, measurements, adjudications or results. Copy them into a new ignored `evidence/.local/` directory and follow [the protocol](../../../docs/rajiv/history/HUMAN-EVALUATION.md). Keep raw downloaded image-review JSON and its packet together; these CSVs do not replace that checker format.

`sessions.csv` records session configuration and prior exposure. `trials.csv` records all actual attempts, including failures/timeouts; `adjudication.csv` records actual disagreements and decisions. Use anonymous aliases, synthetic image/case IDs and correct CSV quoting. Keep free-text private until reviewed. Do not commit filled records by default. Unknown measurements are blank with an explanatory note; `na` means not applicable. None of these templates authenticates identity, timestamps or human work.

Use `evidence/.venv/bin/python -B -m evidence.evals.study_report --sessions PATH --trials PATH --output NEW_JSON` to validate and summarize returned records offline. Exact record requirements and interpretation are in the protocol. Blank templates produce `no_observations`; no participant/timing result is created. The report keeps sessions/modes and retries separate, preserves noncompletion denominators, and compares against provisional authored development references only. It neither reads credentials nor opens provenance paths supplied in the CSVs.
